# АИС «Агентство по трудоустройству»

Репозиторий учебного проекта по теме № 21 «Разработка информационной системы
для агентства по трудоустройству» (ПМ.07, УП.07).

## Назначение системы

Автоматизация поиска вакансий, учёта соискателей, работодателей и вакансий,
ведения трудовых договоров, формирования отчётности и печатных форм.

## Роли

- **Соискатель** — работа с резюме, поиск и просмотр вакансий, отклики
  на вакансии, проверка статуса отклика.
- **Работодатель** — размещение вакансий, просмотр откликов и резюме,
  заключение договоров.
- **Администратор** — управление пользователями, справочниками
  и контроль данных.

## Ветки

- `main` — основная ветка с описанием проекта.
- `PR1_2` — ветка практической работы № 1.2: Use-Case диаграмма
  и спецификации тринадцати прецедентов.
- `PR1_3` — ветка практической работы № 1.3: ERD, SQL-скрипт
  и спецификация базы данных.

## Практическая работа № 1.2

В ветке `PR1_2` размещены:

1. Диаграмма вариантов использования АИС «Агентство по трудоустройству»
   (VSDX, PNG и PDF). На диаграмме 13 прецедентов и три актора — Соискатель,
   Агент и Администратор.
2. Спецификации всех тринадцати прецедентов диаграммы:
   - три прецедента соискателя — «Работа с резюме», «Работа с вакансиями»,
     «Проверка статуса»;
   - семь прецедентов агента — «Учёт соискателей и работодателей», «Подбор
     кандидатов на вакансию», «Управление договорами», «Создание отчётов»,
     «Отчёт по вакансиям», «Отчёт по трудоустроенным», «Отчёт
     по эффективности инспекторов»;
   - три прецедента администратора — «Управление системой», «Управление
     справочниками», «Контроль отчётности».

## Практическая работа № 1.3

В ветке `PR1_3` размещены материалы по созданию базы данных
АИС «Агентство по трудоустройству»:

1. ERD логической модели данных в оформлении по образцу — 14 таблиц
   и 14 связей (VSDX, PNG и PDF).
2. SQL-скрипт `PR1_3_agency_employment.sql`, который создаёт базу
   `ais_agency_employment` в PostgreSQL, таблицы, ограничения, индексы,
   представления и первичные данные.
3. Спецификация базы данных с описанием всех таблиц, полей, связей,
   индексов, ограничений CHECK и представлений (DOCX и Markdown).

База данных включает таблицы авторизации `authorizations` и пользователей
`users`, связанные «один к одному»; роли хранятся в справочнике `roles`.
Пароли хранятся в виде bcrypt-хешей, сформированных расширением `pgcrypto`.
Тестовые учётные записи: `seeker01` / `Seeker123!`, `seeker02` / `Seeker123!`,
`employer01` / `Employer123!`, `employer02` / `Employer123!`,
`admin01` / `Admin123!`.
