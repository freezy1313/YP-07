# АИС «Агентство по трудоустройству»

Репозиторий учебного проекта по теме № 21 «Разработка информационной системы
для агентства по трудоустройству» (ПМ.07, УП.07).

## Назначение системы

Автоматизация поиска вакансий, учёта соискателей, работодателей, вакансий,
сделок и трудовых договоров, а также формирование отчётности и печатных форм.

## Роли

- **Соискатель** — поиск вакансий, подача заявки, просмотр статуса заявки.
- **Агент по трудоустройству** — ведение вакансий, подбор кандидатов,
  оформление сделок и трудовых договоров, отчёты.
- **Администратор** — управление пользователями, блокировка учётных записей,
  ведение справочников.

  и спецификации трёх прецедентов.

## Практическая работа № 1.2

В ветке `PR1_2` размещены:

1. Диаграмма вариантов использования АИС «Агентство по трудоустройству»
   (PNG и PDF).
2. Спецификации прецедентов:
   - UC-01 «Подать заявку на вакансию»;
   - UC-02 «Оформить трудовой договор»;
   - UC-03 «Управлять учётными записями пользователей».
